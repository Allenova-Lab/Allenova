# AI-Driven Evacuation Routing for Safer Schools

An AI-assisted emergency evacuation concept designed to improve school safety during real-time crises such as chemical leaks, fires, and crowd congestion.

This project explores how adaptive routing, evacuation modeling, and AI-generated path optimization could improve emergency response systems in schools.

## Inspiration
This project was inspired by a real chemical leak incident at my school that caused panic and confusion during evacuation procedures.

## Topics
- AI-assisted routing
- Emergency evacuation systems
- School safety
- Crowd-flow modeling
- Public-interest AI
